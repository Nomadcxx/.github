Measured 2026-10-26. Repository names, default branches, GitHub license detection, and workflow paths come from the live GitHub API. Project license statements, release details, and package sources use the audited project files and release records named in each row. The 17 project rows preserve the audited source repositories; the final two rows record the Arch and Void package sources. `sysc-compositor` remains in the audit inventory as WIP and is outside this rollout.

`Release shape` records the agreed target contract. `Current workflow files` and `Release trigger` record what exists today. At audit time no project default branch had a protection rule or ruleset; the six in-scope rows below now carry the `default-branch-gates` ruleset, and every other row is still recorded as ungated. `Required check-run names` records the exact verification, vulnerability, and project-specific native or packaging checks that Task 3 enforces for in-scope rows; the out-of-scope WIP row is skipped.

`sysc-greet` source is **GPL-3.0-only**. Its package metadata must retain attribution for the separately licensed code and model assets included in its bundle.
